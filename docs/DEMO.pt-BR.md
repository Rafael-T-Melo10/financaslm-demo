# Demonstração local

Siga o README e entre como `alex@example.com` usando a senha de `.env`. Explore receitas, despesas, cartões, parcelas e recorrências. Importe `samples/fictional-pay-statement.pdf` como Holerite; todo o conteúdo é inventado.

Depois, saia e entre como `sam@example.com`. As contas não compartilham uma família e os registros de Alex não devem aparecer para Sam. O assistente mostra que está desabilitado. Gmail e WhatsApp não precisam de configuração para esta demonstração.

Para experimentar Ollama posteriormente, use apenas dados fictícios, configure o runtime/modelo no `.env` e habilite `ASSISTENTE_HABILITADO`. O repositório não inclui modelo nem comprova a exatidão das respostas geradas.
